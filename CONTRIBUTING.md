# Contributing to Dino Server

Thanks for helping improve Dino Server.

## What is welcome

- bug fixes and reliability improvements;
- launcher and diagnostics improvements;
- documentation and localization;
- tests and code cleanup;
- changes to Dino Server's own source code and project-created assets.

## What must not be submitted

Do not commit or attach:

- APK or IPA files;
- game cache files;
- original game artwork, audio, textures, models, video, or other proprietary game assets;
- extracted client data that you do not have permission to redistribute;
- credentials, tokens, private player data, or personal save files.

Keep changes focused and explain the user-visible behavior in the pull request description.

By contributing, you agree that your contribution may be distributed under the repository's GNU GPL v3.0 license.
